# 极热无风源荷失衡模型汇报 PPT

## 文件

- `极热无风源荷失衡模型介绍.pptx`：10 页中文科研汇报稿。
- `极热无风源荷失衡模型介绍_预览.png`：全部页面拼图预览。

## 页面结构

1. 封面
2. 研究背景与问题定义
3. 研究思路与总体框架
4. 极热无风源荷失衡模型
5. 基准 DC-OPF/MIQP 与算例设置
6. 基准 OPF：能量缺口与网络约束
7. 极热条件下元件热故障概率
8. 蒙特卡洛场景与故障后 OPF
9. 故障后切负荷分布与风险主导因素
10. 主要结论、模型边界与展望
